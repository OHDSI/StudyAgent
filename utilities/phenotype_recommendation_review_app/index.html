Recommendation tuning

Tune the phenotype recommendation flow by testing stage. These controls affect how many candidates are retrieved, how many are allowed into planning, and how many can survive into the final response.

Planner breadth

Use this control to test whether ACP planning saw enough plausible options. candidate_limit bounds how many candidates can survive into shortlist planning.

Final output count

Use this control to test how many final recommendations ACP may return. max_results is a hard output cap, but the returned count can still be lower if earlier enforcement or quality gates prune candidates.

Retrieval coverage

Use these controls to test whether the right phenotypes appear early in search. top_k widens the initial retrieval pool, and candidate_offset shifts the search window for paging-style inspection.

Current effective guardrails

These values are read from the most recent ACP response so you can compare your requested settings with the effective planning and enforcement limits used downstream.

Run a recommendation to populate effective limits and stage counts.
Exclude metadata filters

Filters are passed through to ACP as exact metadata exclusions. Leave a field blank to ignore it. Use commas for multiple values.
